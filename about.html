Who I Am

I'm a Mathematics student interested in game development and cybersecurity. I also enjoy chess and reading.

Background

Alongside my studies, I've completed certificates in web development, Python / Python Turtle, and web design. The connection between mathematics, programming, game development, and cybersecurity is what interests me most.

Qualifications

My interest in programming started in 2020, when I earned certificates in web design, web development, and Python / Python Turtle. Over time, my interest in games and cybersecurity grew, and they are the areas I most want to keep learning about. In 2024, I took part in Code Fest and finished in 4th place. This semester, in SITE 1101, I built a logic gates project on a breadboard, and I'm now building this website while working with Git and GitHub.
