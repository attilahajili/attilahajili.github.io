# Atilla Hajili | Personal Website

This project is a personal website for Atilla Hajili, built as part of SITE 1101. The site presents a short introduction, background, project work, and contact information in a clean, light, formal style.

## Purpose

The website is designed to introduce Atilla, share his interests, show his work, and provide a simple place to connect with his GitHub profile. It is focused on a minimal, readable layout with enough personality to feel personal without becoming crowded or overly decorative.

## Pages

- Home — introductory profile section with a profile photo, personal summary, and calls to view the work or learn more.
- About — background, qualifications, and interests.
- Projects — project showcase with Project 1 and project card structure ready for future additions.
- Contact — GitHub call-to-action page.

## Folder structure

- `index.html` — Home page
- `about.html` — About page
- `projects.html` — Projects page
- `contact.html` — Contact page
- `css/` — shared styling files
  - `base.css` — color variables, resets, and base typography
  - `layout.css` — page grids and layout helpers
  - `components.css` — navigation, buttons, cards, footer, and other repeated UI pieces
  - `animations.css` — reveal effects, hover motion, and entrance animations
  - `page.css` — page-specific styles
- `js/` — small JavaScript helpers for navigation and motion
  - `nav.js`
  - `animations.js`
- `images/` — project and profile images

## Technologies used

- HTML for page structure
- CSS for layout, responsive design, and animation styling
- JavaScript for mobile navigation, count-up and timeline animations, scroll reveals, and card motion
- Git and GitHub for version control and repository management
- GitHub Pages for deployment target

## Deployment

This site is designed to be hosted on GitHub Pages from the repository root. After pushing the project to GitHub, open the repository settings and enable GitHub Pages from the main branch. The site will then be served from the repository's Pages URL.
